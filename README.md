# ISSB Officer Personality Intelligence (OPI) Assessment

**Alpha Legends Academy** - Official ISSB OPI Assessment Portal

## Overview

A professional web-based assessment tool evaluating Officer-Like Qualities (OLQs) for ISSB candidates. The assessment measures leadership, decision-making, emotional stability, and team integration.

## Features

✅ **5-Question Comprehensive Assessment**
- Leadership under pressure
- Crisis management
- Team collaboration
- Self-discipline
- Conflict resolution

✅ **Intelligent Scoring System**
- L1-L4 grading scale (1-4 points per question)
- Percentage-based scoring (0-100%)
- Three-tier evaluation profile

✅ **Professional Results Report**
- Leadership & Suitability Score
- OPI Rating Profile
- Key Strengths Analysis
- Areas for Improvement
- Personalized Feedback
- Print-ready Report

✅ **Responsive Design**
- Mobile-friendly interface
- Professional UI with gradient backgrounds
- Smooth animations and transitions
- Print optimization

## Evaluation Tiers

### 🌟 Recommended Profile (85%+)
**Status:** High OLQs - Ready for ISSB
- Exceptional leadership and crisis management
- Strong emotional stability
- Excellent team integration

### 📋 Promising Candidate (65-84%)
**Status:** Good Potential - Targeted Development Needed
- Solid foundational leadership traits
- Need to enhance crisis management
- Work on initiative and assertiveness

### 📈 Needs Development (<65%)
**Status:** Development Path
- Build emotional resilience
- Develop leadership initiative
- Enhance problem-solving skills

## Assessment Structure

### Questions Cover:

1. **High-Pressure Task Management** - Leadership & Organization
2. **Crisis Response** - Adaptability & Decision-Making
3. **Group Decision-Making** - Team Collaboration & Ego Control
4. **Self-Discipline** - Organization & Commitment
5. **Conflict Resolution** - Emotional Intelligence

### Scoring Logic:

```
Per Question:
  L4 = 4 points (Highest)
  L3 = 3 points
  L2 = 2 points
  L1 = 1 point (Lowest)

Total Score Range: 5-20 points
Percentage: (Total / 20) × 100 = 0-100%
```
